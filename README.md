# World Explorer
World Explorer is a modern Next.js application that allows users to explore countries around the world using real API data.

## Features
- App Router
- Dynamic Routes
- Server & Client Components
- Real API Fetching
- Search Functionality
- Static & Dynamic Rendering
- Responsive UI

## API Used
REST Countries API

## Run Locally
npm install
npm run dev
