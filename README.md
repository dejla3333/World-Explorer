# World Explorer

World Explorer is a modern **Next.js application** that allows users to explore countries around the world using real API data. Users can search for countries, view country details, and explore global information through a responsive and interactive interface.

##  Features

- Next.js App Router
- Explore countries using real API data
- Search functionality
- Dynamic routes for country details
-  Server & Client Components
-  Real API Fetching
-  Responsive UI design
-  Static and Dynamic Rendering

## Tech Stack

- Next.js
- React
- JavaScript
- Tailwind CSS
- REST Countries API

## API Used

**REST Countries API**

## Getting Started

Follow these steps to run the project locally.

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

Open your browser:

```
http://localhost:3000
```
